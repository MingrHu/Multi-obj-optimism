# MOBO Desktop

MOBO Desktop 是面向 Windows 工程计算场景的 PySide6 原生工作台。它不复制后端算法，
而是分别通过 `mobo.automation` 服务层执行本机 DEFORM 单/多工步任务，通过 DOE HTTP API
执行采样、代理模型训练、评分对比和优化。

## 启动

先在仓库根目录安装 GUI 可选依赖并启动后端：

```powershell
.\scripts\setup_env.ps1 -WithGui
.\.venv\Scripts\Activate.ps1
mobo-api
```

如果现有 `.venv` 引用了已经卸载或移动的 Python，使用
`.\scripts\setup_env.ps1 -Recreate -WithGui` 重建。仅缺少 PySide6 且虚拟环境本身可用时，
也可执行 `.\.venv\Scripts\python.exe -m pip install -r .\requirements\gui.txt` 补装。

在另一个 PowerShell 中启动界面：

```powershell
.\.venv\Scripts\python.exe .\UI\main.py
```

默认后端地址为 `http://127.0.0.1:5000`，也可在界面顶部修改。使用远程服务时可以预先设置
`MOBO_API_URL`。DEFORM 单/多工步功能始终在启动界面的本机执行；真实求解前需要配置
`MOBO_DEF_PRE_64` 和 `MOBO_DEF_ARM_CTL`，首次验证建议启用“演练模式”。

## 页面与能力

- **单工步计算**：选择模板 KEY、样本和工作区；LHS/全因子抽样，LHS 可选择是否追加边界组合，关闭时严格按指定数量生成；参数化 KEY；并行求解；
  增量提取；批处理状态。
- **多工步批处理**：预置工步定义、联合抽样、换模连续计算、检查点保留、分样本进度与结果提取。
- **代理模型**：导入 TXT/TSV/CSV 后立即把数据副本上传并绑定当前 DOE，或在选中 DOE 后生成并载入 80 行演示数据；配置输入列，
  选择 PRG/SVR/RF/KM/DNN，实时查看训练阶段和评分柱状图；用户选择 DOE 后检查已有训练记录，
  后续字段名称或角色变化可用“保存 DOE 配置”更新而不启动训练；已有可用模型时提示可直接优化，
  并将按钮切换为“重新训练”。状态同步只暂缓训练提交，不阻塞配置保存。
- **优化中心**：单目标、多目标、强化学习三种模式；NSGA-II 与 PPO 使用各自独立参数面板；目标方向、权重和设计变量边界；
  下拉项只显示唯一任务名称并在内部保存 DOE ID，选择后自动从持久化训练记录载入输入字段、训练数据边界
  和输出目标；方向使用最小化/最大化枚举，权重和边界使用数值编辑器，并即时检查权重、上下界与
  训练范围；目标与变量支持添加、删除选中行，完成后的任务显示“重新优化”并在重跑前确认。
- **结果分析**：虚拟化原始数据表、任意输入/输出字段映射、二维折线/柱状/散点、三维散点以及
  TSV/CSV 导出；可查看同一 DOE 的优化运行历史摘要，并加载任一已完成版本，无需查找服务端文件路径。

训练预览、目标/变量配置和结果表都支持横向滚动；拖动表头分隔线可自由调整列宽。结果表使用
按需读取的虚拟模型以承载大数据。二维图支持鼠标滚轮、框选和按钮缩放，三维散点支持滚轮缩放、
拖动旋转以及缩放按钮；大数据绘图会均匀抽样并明确显示原始点数与实际绘制点数。

切换 DOE 时，界面会校验每个异步响应所属的任务和选择版本，过期响应不会覆盖当前页面。训练与
优化的启动/停止按钮按数据、字段、配置和运行状态启用；DOE 列表或状态读取失败会在当前页面显示
原因和重试提示。DOE 列表刷新与训练状态读取会合并连续重复请求，避免重复工作线程同时更新控件。

各工作区只加载 DOE 列表，不会自动替用户选中任务。进入或刷新优化中心时保持当前页面，历史优化
结果不会触发自动跳转；优化中心的 DOE 是只读下拉选项，只能从后端已有任务中选择，列表为空时
保持空状态。需要查看结果时，由用户在“结果分析”中主动选择任务并加载。

训练文件可以有表头，也可以是后端使用的无表头 TSV。无表头文件会显示为“字段 1、字段 2……”；
训练前可通过“编辑字段名称与角色”逐列命名，并指定为输入参数或输出目标；这些名称会原样
用于训练、推理和优化；文件选择完成后自动上传，配置保存后，再次选择 DOE 会从后端数据资源恢复预览、字段角色和原始
文件名（只保存文件名，不保存客户端绝对路径）；优化中心从后端训练记录恢复这些字段。导入训练数据时，全空或全 NaN 列会自动
移除，含局部 NaN/Inf 或非数值单元格的行会排除并显示统计；结果表仍保留原始列用于追溯，
但全 NaN 列不会出现在图表坐标轴选择器中。

## 测试

Qt 无关的协议与数据转换测试始终运行；未安装 GUI 可选依赖时，Qt 导入冒烟测试会自动跳过：

```powershell
pytest tests/unit/ui -q
python tools/check_docs.py
```
